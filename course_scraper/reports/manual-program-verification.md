# Programme source and webpage verification

Reviewed 270 indexed programme records against their official source and actual local and production webpages.

This is individual agent semantic review, with automated checks added for coverage. It is not human sign-off or a guarantee that the university sources are correct. Production has not been updated.

The full production scraper pipeline was not run. Public programme sources were fetched; source extraction, structured choice rules and safety validation were rerun separately without remote database writes.

## Resulting local display

Safety counts: {'warning': 232, 'ok': 24, 'blocked': 14}. Maps are withheld where structure or credits cannot be verified. Uncoded course descriptions and restrictions remain visible as source text. A programme without coded rows shows original syllabus prose rather than an incomplete inferred course list.

Course groups preserve the official selection wording. Semester headers no longer sum mutually exclusive alternatives. Cards identify full course credit totals and continued courses. Unmarked compulsory flags receive neutral labels, and unreviewed generated English rule summaries are hidden.

Important cases: HLD1K retains Scripting for Level Design and Architectural History as uncoded notes; TFY2M Geophysics is withheld because two alternative layouts are not parsed safely; TMA2M and TMV2M are withheld because named tracks were flattened; MMF2M is withheld for contradictory source credits; SNE2M retains all four semester descriptions; TMV2Y retains all nine external-course references, including the conflicting Swedish/English waste-management code; SRE2M warns about conflicting Russian-language requirements between its outline and programme syllabus.

## Validation

Final checks: 122 Jest suites / 1,717 tests passed; 110 Python tests passed; npm lint, TypeScript, changed-file Ruff and git diff --check passed. The 270-record cached-source safety audit reports no errors or metadata drift. All 3,614 stored coded-course occurrences match official full course credit totals. These totals are distinct from per-semester shares, alternative-course sums and uncoded partner courses.

React Doctor completed with four warnings (86/100): two component-complexity warnings, an index used in a static source-note key, and an exported pure caption helper. These are recorded as maintainability observations; they did not identify a confirmed course-content regression. Its diagnostics are preserved under work/program-verification/react-doctor-diagnostics.

The JSON report contains each original review, observed omissions, unsupported content, track checks, revision applicability, source references, production differences and additional page evidence. Findings describe snapshots and may predate fixes; the safety and local display columns below describe the resulting disposition.
